# Rendering

How notes display attachments stored with Depot.

- [ ] `RND-001` Private images display without making them public.
- [ ] `RND-002` Reading view displays Depot attachments.
- [ ] `RND-003` Live Preview displays Depot attachments.
- [ ] `RND-011` Bases card covers display Depot images.
- [ ] `RND-004` Displaying an attachment never changes the note.
- [ ] `RND-007` Searching notes never downloads attachments.
- [ ] `RND-008` Attachments in notes download only when they scroll into view.
- [ ] `ATT-002` Image references display inline.
- [ ] `ATT-003` PDF references display inline.
- [ ] `ATT-004` Audio references play inline.
- [ ] `ATT-005` Video references play inline.
- [ ] `ATT-006` Other files open from their link.
